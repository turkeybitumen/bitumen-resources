# Bitumen Resources

A collection of educational resources about bitumen, asphalt, road construction and petroleum products.

## About Bitumen

Bitumen is a petroleum-based material widely used in road construction, asphalt production, waterproofing and various industrial applications.

## Common Bitumen Types

- Penetration Grade Bitumen
- Oxidized Bitumen
- Polymer Modified Bitumen
- Cutback Bitumen

## Applications

Bitumen is commonly used for:

- Road construction
- Asphalt production
- Waterproofing
- Infrastructure projects
- Industrial applications

## Bitumen Grades

Different bitumen grades are selected according to project requirements, climate, application and technical specifications.

## Asphalt and Road Construction

Bitumen is an important binding material in asphalt mixtures used for roads, highways and other transportation infrastructure.
